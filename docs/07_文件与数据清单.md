## 一、脚本（`~/cobot_magic/`）

| 文件 | 作用 | 什么时候用 |
|------|------|-----------|
| `bringup.sh` | 上电总入口：`can` / `arms` / `cams` / `check` / `armstop` / `stop` / `status` / `collect` | 每天开工 |
| `record_here.sh` | **空格**触发采集，自动质检、不合格自动改名 | 采数据（推荐） |
| `collect_timed.sh` | 倒计时自动开录（双手都占着时用） | 采数据（备选） |
| `train_cube.sh` | 训练：自动数条数 → 质检 → 训练 → 打印下一步 | 训练（推荐） |
| `run_policy.sh` | 上机推理：检查 → move_home → 起 inference.py | 跑策略 |
| `run_trials.sh` | 连续跑 N 轮，每轮后留时间复位方块 | 统计成功率 |
| `move_home.py` | 把双臂慢慢推到数据集起始姿态中位数 | 每次推理前（脚本自动调用） |
| `check_act_data.py` | 单条/整批质检（8 项） | 采完数据、训练前 |
| `check_spread.py` | 统计"夹住瞬间右臂姿态"的离散度 | 验证随机位置数据是否真的采开 |
| `eval_ckpt.py` | 离线评估一个权重（不用机械臂） | 训练后选权重 |
| `dump_timeline.py` | 打印某条示范的示教/预测夹爪时间线 | 排查夹爪时机问题 |
| `analyze_trials.py` | 解析 `run_trials.sh` 日志，判定每轮成败 | 批量测试后 |
| `diag_joints.py` | 打印主从臂跟随误差 | 自检/怀疑主从异常 |
| `armctl.py` / `armctl.sh` | 查询/控制 4 条臂的使能状态 | `bringup.sh status` 调用 |
| `home_pose.py` | 早期脚本：读数据集起始姿态 | 一般不用 |
| `train_curve.png` | 早期训练曲线截图 | 可删 |

子目录：

| 目录 | 内容 | 大小 |
|------|------|------|
| `aloha-devel/act/` | ACT 算法（`train.py` / `inference.py` / `policy.py` / `utils.py` / `detr/`） | 364 KB |
| `aloha-devel/robomimic/` | 自带精简版 robomimic（**不要 pip 装官方包**） | 2.2 MB |
| `aloha-devel/train/` | 2024 年老权重（`policy_best` 等 4 个 × 425 MB） | **1.6 GB（可删）** |
| `collect_data/` | 采集程序 `collect_data.py`、回放 `visualize_episodes.py`、示例视频 | 78 MB |
| `camera_ws/` | 相机 ROS 工作区（`grasp_2cams.launch` 在这里） | 104 MB |
| `Piper_ros_private-ros-noetic/` | 机械臂 ROS 工作区（`start_ms_piper.launch`） | 22 MB |
| `camera_ws.zip` | 相机工作区压缩包（已有解压版） | 29 MB（可删） |
| `docs/` | 本套教程 + 10 cm 方格纸 | 很小 |

## 二、数据（`~/data/`）

| 目录 | 内容 | 大小 | 处置 |
|------|------|------|------|
| `grasp_cube/` | **当前任务数据**：51 条 × 400 帧，固定方块位置 | **36 GB** | **保留** |
| `grasp_cube_rand/` | 计划中的 10 cm 随机位置数据集（40 条） | 约 28 GB | 待采集 |
| `_archive_grasp_test_badcams/` | 早期相机映射接错时采的废数据 | 3.9 GB | 可删 |
| `act_smoke/` | 冒烟测试数据 | 1.1 GB | 可删 |
| `aloha_mobile_dummy/` | 早期 dummy 数据 | 1.1 GB | 可删 |

单条示范的结构（`episode_N.hdf5`，约 700 MB）：

```
/action                          (400, 14) float32   ← 主臂角度（人手动作）
/base_action                     (400, 2)  float32   ← 全零
/observations/qpos               (400, 14) float32   ← 从臂实测（含夹爪）
/observations/qvel               (400, 14) float32
/observations/effort             (400, 14) float32
/observations/images/cam_high        (400, 480, 640, 3) uint8   ← 头视
/observations/images/cam_right_wrist (400, 480, 640, 3) uint8   ← 右腕
```

按约定：索引 0–6 = 左臂（夹爪 6），7–13 = 右臂（夹爪 13）。

## 三、权重（`~/train_*`）

| 目录 | 内容 | 大小 | 说明 |
|------|------|------|------|
| `train_cube_v3/` | 51 条数据训练，23 个 epoch 权重 | 8.2 GB | **当前在用** |
| └ `policy_epoch_2100_seed_0.ckpt` | **当前最佳**（右臂 MAE 0.0549 rad） | 380 MB | **必须保留** |
| └ `dataset_stats.pkl` | 归一化统计，**必须和 ckpt 配对** | 23 KB | **必须保留** |
| └ `train.log` / `train_val_*.png` | 训练日志与曲线 | 小 | 保留（追溯用） |
| `train_cube_v2/` | 旧版（11 个权重） | 3.9 GB | 可删（历史参考） |
| `train_cube_v1/` | 旧版（`policy_best.ckpt`） | 364 MB | 可删 |
| `train_smoke10/` | 10 epoch 冒烟测试 | 1.6 GB | 可删 |

**权重必须和 `dataset_stats.pkl` 一起用**：ckpt 只存网络参数，归一化用的均值/方差在 pkl 里。
两者不配套 → 动作整体偏移。

## 四、可以清理什么（约 13 GB）

确认不需要历史对照后再执行：

```bash
# 1) 早期废数据（相机映射接错）
rm -rf ~/data/_archive_grasp_test_badcams          # 3.9 GB
rm -rf ~/data/act_smoke ~/data/aloha_mobile_dummy  # 2.2 GB

# 2) 旧权重
rm -rf ~/train_cube_v1 ~/train_smoke10             # 2.0 GB
# rm -rf ~/train_cube_v2                           # 3.9 GB（想留对比就先别删）

# 3) 仓库里 2024 年的老权重
rm -rf ~/cobot_magic/aloha-devel/train             # 1.6 GB

# 4) 其他
rm -f ~/cobot_magic/camera_ws.zip                  # 29 MB（已有解压版）
rm -f ~/cobot_magic/train_curve.png
rm -rf ~/cobot_magic/collect_data/out*.mkv
find ~/cobot_magic -name __pycache__ -type d -prune -exec rm -rf {} +
```

**绝对不要删**：

- `~/data/grasp_cube/`（36 GB，重采要 3 小时）
- `~/train_cube_v3/policy_epoch_2100_seed_0.ckpt` + `~/train_cube_v3/dataset_stats.pkl`
- `~/cobot_magic/aloha-devel/{act,robomimic}/`（改过的算法代码）
- `~/cobot_magic/camera_ws/`、`~/cobot_magic/Piper_ros_private-ros-noetic/`（编译好的工作区）

训练新数据集时，权重会以 380 MB / 100 epoch 的速度堆积：

```bash
# 只保留 500 的倍数 + 2100（按需改）
cd ~/train_grasp_cube_rand
ls policy_epoch_*.ckpt | grep -vE "_(500|1000|1500|2000|2100|2500|3000)_" | xargs -r rm -v
```

## 五、备份 / 迁移

### 只备份代码和文档（推荐，几 MB）

```bash
cd ~
tar -czf ~/cobot_magic_code_$(date +%Y%m%d).tar.gz \
  --exclude='__pycache__' \
  cobot_magic/README.md \
  cobot_magic/docs \
  cobot_magic/*.sh \
  cobot_magic/*.py \
  cobot_magic/aloha-devel/act \
  cobot_magic/aloha-devel/robomimic \
  cobot_magic/aloha-devel/act_env.sh \
  cobot_magic/aloha-devel/requirements.txt \
  cobot_magic/collect_data/collect_data.py \
  cobot_magic/collect_data/visualize_episodes.py

ls -lh ~/cobot_magic_code_*.tar.gz
```

### 连数据和权重一起备份

数据和权重太大（50 GB+），建议直接对拷移动硬盘：

```bash
rsync -avP ~/data/grasp_cube ~/train_cube_v3 /media/agilex/<硬盘>/aloha_backup/
```

### 迁移到新机器要准备什么

1. **系统环境**：Ubuntu 20.04 + ROS Noetic + conda 环境 `aloha`（Python 3.8，torch 1.10+cu113）
2. **代码**：上面的 tar 包解压到 `~/cobot_magic`
3. **ROS 工作区要重新编译**（不同机器的路径/依赖可能不同）：
   ```bash
   cd ~/cobot_magic/camera_ws   && catkin_make && source devel/setup.bash
   cd ~/cobot_magic/Piper_ros_private-ros-noetic && catkin_make && source devel/setup.bash
   ```
   （也可以用上面 tar 包里的源码自己建工作区，`devel/` 是编译产物，不必带走）
4. **数据 + 权重**：`~/data/grasp_cube`、`~/train_cube_v3`（至少 ckpt + dataset_stats.pkl）
5. **相机序列号**：`grasp_2cams.launch` 里写死了 `CC1S74100TL` / `CC1S74101HL`，换机器/换相机会对不上，要改
